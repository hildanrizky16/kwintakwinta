# Kwintakwinta

Aplikasi kuitansi untuk membantu pelaku usaha membuat dan mengelola kuitansi.

- **Demo:** https://hildanrizky16.github.io/kwintakwinta/
- **Repositori kode:** https://github.com/hildanrizky16/kwintakwinta

## Isi proyek

Repositori ini berisi halaman HTML dan kode JavaScript aplikasi. Berkas yang terlihat di repositori antara lain:

- `index.html` — halaman awal aplikasi
- `login.html` dan `login.css` — halaman dan gaya untuk login
- `dashboard.html` dan `dashboard.js` — halaman dashboard
- `customer.js` — kode terkait pelanggan
- `kwitansi.html` dan `kwitansi.js` — halaman dan kode kuitansi
- `laporan.html` dan `laporan.js` — halaman dan kode laporan
- `app.js` dan `auth.js` — kode aplikasi dan autentikasi

## Menjalankan aplikasi

1. Unduh repo melalui **Code → Download ZIP**, lalu ekstrak, atau clone dengan Git:

   ```bash
   git clone https://github.com/hildanrizky16/kwintakwinta.git
   ```

2. Buka folder proyek dan jalankan `index.html` di browser.
3. Jika halaman tidak berfungsi saat dibuka langsung, jalankan folder ini melalui server web lokal sederhana. Periksa juga konfigurasi layanan eksternal yang mungkin diperlukan aplikasi.

> Catatan: konfigurasi layanan eksternal dan langkah build APK belum didokumentasikan di repo ini. Lengkapi bagian ini jika aplikasi membutuhkan layanan seperti Firebase atau jika proyek sudah memiliki proses untuk menghasilkan APK Android.

## Mengembangkan proyek

1. Fork repo ini di GitHub, atau clone repo ke komputer.
2. Buat branch baru untuk perubahan yang akan dikerjakan.
3. Uji perubahan di browser.
4. Ajukan pull request agar perubahan dapat ditinjau.

Silakan sertakan ringkasan perubahan dan langkah untuk mengujinya saat mengirim pull request.
